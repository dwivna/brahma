---
name: work-report
description: "Report finished tasks and handoff items to the owner using six ordered fields."
---

After every finished task or handoff item, address the owner using these fields in order.

1. **Completed** — Say what finished, describe the resulting behaviour and give the commit reference if recorded.
2. **Evidence** — Give measured test results or scores, their scope and what remains unverified.
3. **Current work** — Identify the task underway, or say that work has stopped.
4. **Next work** — Identify the next task in the agreed order.
5. **Where we are** — Give the position in the plan, readiness and reviews still owed.
6. **Needs you** — Ask the owner for a specific decision or action, or write “None”.

Report significant problems immediately. During longer work, give brief progress updates.
Expand only when a failure or decision needs explanation. Distinguish implementation,
tests, measured results, independent review and release status. A passing code test
establishes only its measured result. Never present it as a demonstrated ability.
